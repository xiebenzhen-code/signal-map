# 跨行业验收：浏览器、调用日志与费用口径

适用：本轮本地候选，尚未部署。共享线上入口/API007/Web010不会因为本地修改而自动更新。

## 来源与准入

- 发现层继续使用现有公共网页、公司/官方页面、论文、社区和用户自选来源；本轮没有增加新的爬虫、付费来源或绕过来源访问限制。
- 已知GitHub映射是补充来源，不是全行业内容库。未知具体实体不再触发所有默认AI仓库；宽泛编码/CLI问题仍可按主题发现默认项目。
- 来源真实、权威、高新鲜度都不能替代相关性。泛化文档词不能单独证明主题匹配。
- 对相关的新材料保留正例，避免全部拒绝。旧材料可以作为明确标识的背景证据，不得说成时间窗口内的新变化。
- 90天从自然语言→请求→计划→检索→本地保存/恢复均需保留。未支持的显式数字天数在页面提示，不偷偷改成7天；用户主动选择时间选项优先。
- 本轮未完整实现任意地区、版本的语义验证器；原题中的地区、版本仍保留于currentQuestions。语义匹配质量要由线上场景验证，不能凭单元测试称跨行业修复完成。

## 浏览器：每题必须有的观测

真实浏览器打开正确共享入口，在验收时为页面添加 `?observe=1`（已有查询参数用 `&observe=1`）。用户自己输入凭据。每题只点击一次。

新日志 `stage=browser_research` 仅在这个显式观察模式下输出到浏览器控制台，不发送到额外的遥测服务：

- requestId：与API关联；演示模式没有请求则为null。
- firstFeedbackMs：提交处理开始到可见加载状态的下一帧机会；没观察到独立加载画面就为null。
- visibleCompletionMs：检测到可见结果/错误状态后的下一帧机会；是可见DOM/帧机会观测，不是精密的屏幕像素绘制时间。
- outcome：completed/failed/incomplete；completed仅说明请求处理及页面状态完成，不证明答案正确。
- longTaskCount/maxLongTaskMs：浏览器支持Long Tasks时提供，否则为null；不能单凭零长任务断言无卡顿。

60秒未取得可见完成会记录incomplete；此时不能把该时长当作真实完成时间。切走页面、浏览器不支持、观测没拿到，都标UNKNOWN。不使用API耗时给白屏、流畅度、按钮状态打分。

需人工/浏览器操作补充：开始前、等待中（若可见）、结束后的截图或可见状态；按钮是否禁用；错误是否可理解；刷新后能否读回。没有截到等待画面不能伪造。

## 模型调用与Token

`/api/signals`响应新增 `modelUsage`；服务端结构化日志 `event=model_call`，包括requestId、provider、model、stage（planning/synthesis）、durationMs、httpStatus、transportStatus、errorCode、usage、cost。

这些记录由真正的HTTP传输函数产生，不由“提取了多少claim”等结果倒推。没有配置导致未调用时不伪造一次调用。供应商返回的usage仅取非负数值字段；没有返回则为null，不按0计。

注意边界：

- scope=finished_transport_calls：仅覆盖本次请求中已结束并被记录的模型传输；不是供应商全部账单。晚到调用可在相同requestId日志中补齐。
- transportStatus=completed不等于模型输出通过结构、证据或语义校验。
- callCount是已记录的传输数，不等于研究题数或claim数。
- reportedTotalTokens仅累加已提供的total字段；usageCompleteness标记none/partial/complete/not_called。部分用量不得当总用量。
- cost=null，billingComplete=false。按用户可取得的实际账单另填模型费用、平台用量、币种、计费时间段，不能把未知成本写成0。
- 不记录prompt、completion、密码、Cookie、Token、数据库连接串或用户身份。
