## 3. 必须维持的设计规则
1. 正式结果、不确定材料、读取失败分开。UNCERTAIN 不当作确认结论；相关性通过也不等于事实已核验。
2. 每张正式卡片需要原文与日期，并提供相对标题有增量的内容；只有标题或残缺片段时明确标注，不用复制标题凑摘要。
3. 导航、栏目和订阅套话不得成为正式信号；“为什么值得关注”必须联系用户问题与现有证据，不能只有通用模板。
4. 零展示应区分未取得材料、来源失败、未搜索、关系不确定和过滤为空。不能由零条推出“没有新变化”。
5. “误零”指有值得保留的材料却因传参、解析或误拒整批归零；不以保证非零或降低门槛代替修复。
6. 来源只取得最近 N 条时写出实际取得数量与日期范围，不声称涵盖用户要求的整个时间窗口。
7. 旧研究结果须与当前运行和版本区分；不能仅因加载了历史卡片就判新版本回归或宣称新研究成功。
8. 登录后会话可恢复、退出后边界清楚、账号间数据隔离。一次已有会话导航成功不等于完整重新登录验收。
9. 保留地址预检、逐跳校验与凭据头部传输；不为增加结果放宽安全、日期或可靠性门槛。
